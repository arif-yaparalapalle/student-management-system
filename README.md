 # Student Management System
-----------------------------------
## Introduction
Student Management System is a Python-based console application used to manage student details.

## Project Objective
The main objective of this project is to store and manage student information easily.

## Technologies Used
- Python
- JSON

## Features
1. Add Student
2. View Students
3. Search Student
4. Update Student
5. Delete Student
6. View Total Number of Students

## Validations
- Student ID must be a positive number.
- Duplicate Student IDs are not allowed.
- Student Name cannot be empty.
- Age must be a positive number.
- Course Name cannot be empty.
- Invalid inputs are handled using Exception Handling.
- Delete confirmation is provided before deleting student details.

## Data Storage
Student details are stored in a JSON file named students.json.

## Python Concepts Used
- Variables
- Data Types
- Conditional Statements
- Loops
- Functions
- Lists
- Dictionaries
- Exception Handling
- File Handling
- JSON Module
- String Formatting

## Project Files
- main.py - Contains the Python project code.
- students.json - Stores student details.
- README.md - Contains project documentation.

## How to Run the Project
1. Open the project in Visual Studio Code.
2. Open the terminal in the Python Projects folder.
3. Run the following command:

   python "student management system/main.py"

4. Select an option from the main menu.

## Conclusion
This project helps to manage student details using Python and JSON file handling.
